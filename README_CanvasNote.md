# CanvasNote

学校での授業を想定した学習支援Webアプリケーションです。

先生が教材を作成・管理し、生徒への教材配布やクイズの出題、生徒の回答・自動採点、結果確認までを一つのシステム上で行えることを目的として制作しました。

---

## 概要

CanvasNoteでは、先生と生徒それぞれの役割に応じて機能を利用できます。

### 先生

* 教材の作成・編集
* 教材の管理
* クラスの管理
* 生徒の管理
* クイズの作成
* クイズの編集・削除
* クイズの出題・非公開
* 生徒の回答結果の確認

### 生徒

* 教材の閲覧
* クイズの確認
* クイズへの回答
* クイズの提出
* 自動採点結果の確認

---

## 主な機能

### ログイン機能

Laravelの認証機能を利用してログインを行います。

ログインしているユーザーの権限を確認し、先生と生徒で利用できる機能を分けています。

```text
ログイン
  ↓
ユーザー情報を確認
  ↓
先生 / 生徒を判定
  ↓
権限に応じた画面・機能を表示
```

---

### 教材管理

先生は教材を作成・編集し、教材を管理できます。

教材の編集画面ではキャンバスを利用して、教材の内容を作成できます。

キャンバス機能にはFabric.jsを使用しています。

---

### クラス・生徒管理

先生はクラスや生徒を管理できます。

クラスと生徒の情報を利用して、クイズを出題する対象を指定できます。

---

### クイズ機能

先生は教材に関連付けたクイズを作成できます。

クイズには以下のような設定があります。

* クイズタイトル
* 対象教材
* 出題形式
* 問題
* 選択肢
* 正解
* 出題対象クラス

作成したクイズは、公開・非公開を切り替えることができます。

---

### クイズの自動採点

生徒がクイズを提出すると、選択した回答と登録されている正解を比較して自動的に採点します。

```text
生徒が回答
   ↓
回答を送信
   ↓
Laravelで正解と比較
   ↓
正解数を計算
   ↓
得点を計算
   ↓
結果をデータベースに保存
```

得点だけでなく、

* 得点
* 正解数
* 問題数
* 回答日時

などを保存しています。

---

### クイズ結果の確認

先生はクイズごとに生徒の回答状況を確認できます。

例えば、

```text
山田さん　回答済み　80点
佐藤さん　未回答
田中さん　未回答
```

のように、対象となる生徒の回答状況や得点を確認できます。

---

## データの保存と通信

データの保存にはMySQLを使用しています。

LaravelとVue.jsの間でデータをやり取りする際にはJSONを使用しています。

```text
Vue.js
   ↓
Laravel
   ↓
MySQL
   ↓
Laravel
   ↓
JSON
   ↓
Vue.js
```

例えばクイズ一覧を取得する際には、Laravelがデータベースから情報を取得し、JSON形式でVue.jsへ返します。

## システム構成

CanvasNoteは、主に以下の構成で動作しています。

```text
┌───────────────┐
│   Vue.js      │
│  画面・操作    │
└───────┬───────┘
        │ JSON
        ↓
┌───────────────┐
│    Laravel    │
│ 認証・処理・API │
└───────┬───────┘
        │
        ↓
┌───────────────┐
│     MySQL     │
│    データ保存   │
└───────────────┘
```

---

## クイズ機能のデータフロー

```text
【先生】

クイズを作成
    ↓
Laravelで登録
    ↓
MySQLに保存
    ↓
対象クラスへ出題
    ↓

【生徒】

クイズを取得
    ↓
問題に回答
    ↓
回答を送信
    ↓

【Laravel】

正解と回答を比較
    ↓
自動採点
    ↓
結果をMySQLに保存
    ↓

【先生】

結果を取得
    ↓
生徒の得点・回答状況を確認
```

---

## クイズの公開管理

クイズには公開状態があり、先生が出題・非公開を切り替えられます。

```text
下書き
  ↓
出題する
  ↓
出題中
  ↓
非公開にする
  ↓
下書き
```

また、公開中のクイズは編集できないようにすることで、出題後に問題内容が変更されることを防いでいます。

## 起動方法

### 1. プロジェクトを取得

```bash
git clone <リポジトリURL>
cd CanvasNote
```

### 2. PHPパッケージをインストール

```bash
composer install
```

### 3. JavaScriptパッケージをインストール

```bash
npm install
```

### 4. 環境設定

`.env.example` をコピーして `.env` を作成します。

```bash
copy .env.example .env
```

必要に応じて `.env` のデータベース設定を変更してください。

### 5. アプリケーションキーを生成

```bash
php artisan key:generate
```

### 6. データベースを設定

MySQLにデータベースを作成し、`.env` に接続情報を設定します。

その後、マイグレーションを実行します。

```bash
php artisan migrate
```

### 7. Laravelを起動

```bash
php artisan serve
```

### 8. フロントエンドを起動

別のターミナルで、

```bash
npm run dev
```

を実行します。

## 制作目的

学校での授業では、教材の作成、配布、生徒の回答確認、クイズの採点など、さまざまな作業が発生します。

そこで、これらの作業を一つのWebアプリケーションにまとめることで、先生と生徒の双方が利用しやすい学習環境を作ることを目的として制作しました。
